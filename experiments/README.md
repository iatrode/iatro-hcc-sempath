# Experiments

This directory contains the active HCC-SemPath mechanism-study protocols.
Generated checkpoints, logs, tables, figures, review packages, and cohort
records are written to external experiment storage.

The currently tracked protocol is the matched full-population A0-A6 mechanism
study under [`ablation/`](ablation/README.md). Additional evaluation protocols
are added with frozen cohort, endpoint, and leakage contracts.
